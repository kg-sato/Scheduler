# Liquid strata background

Original SVG marbling inspired by the supplied Photoroom reference: https://cdn.photoroom.com/v2/image-cache?path=gs://background-7ef44.appspot.com/backgrounds_v3/abstract/39_abstract.jpg

- Twenty joined layers in midnight, mint and lilac; fine pearlescent contours and a dark reading veil.
- Shared cubic boundary curves morph over a seamless 32-second cycle. Adjacent surfaces use the same boundary data to avoid cracks.
- Native SVG timelines; no animation library, remote artwork, WebGL context or JavaScript frame loop.
- Pauses for reduced motion, calmer motion, Quiet material, Focus scene and hidden tabs. Static artwork remains visible.
- Existing phone framing, high-contrast hiding and foreground UI are preserved.

Local source and generated copies updated. Real-device performance has not been benchmarked.

## Scene identity and centerpiece

Each tab carries a restrained accent: mint for My Day, lilac for Assignments, ice blue for Atlas, apricot for Rhythm, and moonlight blue for Focus. These tint navigation surfaces and the date plaque alongside the existing background color shifts.

The hero now contains an original depth-sorted trefoil sculpture, drawn as SVG tube segments. A seamless 28-second turn adds gentle dimensional movement without a JavaScript frame loop. Calmer motion and Quiet mode retain a static sculpture; hidden tabs and other pages pause the animation. The date now separates a large day number from its weekday and month/year.
