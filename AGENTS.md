# Project workflow

- Work locally in this Scheduler folder, which is the project opened in VS Code.
- Leave edits uncommitted for the user to review in VS Code Source Control.
- Do not commit, push, merge, or create pull requests unless the user explicitly requests that action. The user normally reviews and pushes changes themselves.
- Keep UI concepts and brainstorming in design/. The root Application.html remains the application source of truth.
